# Етап 6 (Відкладено на потім): Освітній трек Інформатики (7–12) та офлайн-дистрибуція (`P3`)

**Пріоритет:** `P3 — Відкладено на пізніший етап (на поточній стадії — лише файлова структура та заготовки)`  
**Примітка щодо обсягу:** Питання зовнішньої організації розробки самого репозиторію звідси виключено; у межах застосунку лишаються виключно **навчальний трек Інформатики для учнів 7–12 класів** (безпечна робота з Git, `noreply`, `github.dev`, GitHub Pages, Student Pack) та **автономне пакування (PWA / Desktop)**.

---

## 1. Навчальний трек Інформатики (7–12 класи): Безпечна робота з GitHub
Окремі практичні модулі курсу Інформатики без жодної примусової реєстрації для молодших класів:
- **Цифрова гігієна профілю**: приватна адреса `noreply`, двофакторна автентифікація (2FA), базові права доступу.
- **Робота в браузері без складних налаштувань**: знайомство з `github.dev` для редагування шкільних HTML/JS-проєктів.
- **Публікація власних робіт**: безкоштовний хостинг **GitHub Pages** для учнівських сайтів-портфоліо.
- **Можливості для старшокласників**: огляд **GitHub Student Developer Pack** та легальних освітніх ресурсів.

## 2. Автономна дистрибуція (PWA / Desktop)
- **Офлайн-встановлення (PWA)**: кешування активів застосунку та локальних ZIP-пакетів уроків для шкіл без інтернету.
- **Настільні пакети (опційно)**: компактна офлайн-збірка (наприклад, Tauri/Neutralino) для комп’ютерних класів.

## Поточний стан (Фаза 1)
- Закладено структурні заготовки (`src/features/distribution/` та `content/grades/grade-07/subjects/informatics/github-safety/`).
- Повна реалізація виконується після завершення Етапів 1–5.
