# 🧮 ФАЗА 7 [Lite-Dedicated / L]: РУШІЙ СОРОБАН-РАХІВНИЦІ (`PlaceValueAbacusEngine`)

**Рівень складності:** Medium-Dedicated (Окремий розроблювальний модуль для Gemini 3.1 - 3.5 Lite)  
**Мета:** Розробити тактильну рахівницю (соробан/абак) для візуалізації великих чисел (тисячі, мільйони) та групування 10 одиниць у 1 десяток.

---

## 🛠️ 1. Контракт та пропси рушія (`src/engines/place-value-abacus/PlaceValueAbacusEngine.tsx`)

```typescript
export interface PlaceValueAbacusConfig {
  targetValue: number; // наприклад 1245
  columns?: Array<'thousands' | 'hundreds' | 'tens' | 'ones'>;
  instruction?: string;
  allowAutoCombine?: boolean;
}
```

---

## 🎨 2. Інтерактивна механіка та Canvas/SVG

1. **Вертикальні спиці розрядів**:
   - Спиця `Тисячі` ($1000$), `Сотні` ($100$), `Десятки` ($10$), `Одиниці` ($1$).
   - На кожній спиці розміщено намистини, які можна тактильно пересувати вгору та вниз.
2. **Живий суматор та автоматичний перехід**:
   - При пересуванні 10-ї намистини на одиницях виникає анімація схлопування 10 одиниць у 1 намистину десятків.
   - Відображення розкладного числа під кожною спицею.
