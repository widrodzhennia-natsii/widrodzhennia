# 📐 ФАЗА 5 [Lite-Dedicated / L]: РУШІЙ ТРАНСПОРТИРА ТА КУТІВ (`ProtractorAngleEngine`)

**Рівень складності:** Medium-Dedicated (Окремий розроблювальний модуль для Gemini 3.1 - 3.5 Lite)  
**Мета:** Розробити інтерактивний віртуальний транспортир для вимірювання та побудови гострих, прямих і тупих кутів у геометрії 5 класу НУШ.

---

## 🛠️ 1. Контракт та пропси рушія (`src/engines/protractor-angle/ProtractorAngleEngine.tsx`)

```typescript
export interface ProtractorAngleConfig {
  targetAngle: number; // Наприклад 60°
  toleranceDegrees?: number; // Допуск (наприклад ±3°)
  mode?: 'measure' | 'build'; // 'measure' (виміряти кут) або 'build' (побудувати промінь під кутом)
  instruction?: string;
  angleCategory?: 'acute' | 'right' | 'obtuse' | 'straight'; // гострий, прямий, тупий, розгорнутий
}
```

---

## 🎨 2. Інтерактивна механіка та Canvas 2D

1. **Візуальний полотно (Canvas 480x240)**:
   - Базовий промінь $OA$ (горизонтальний).
   - Віртуальний напівпрозорий транспортир зі шкалою від $0^\circ$ до $180^\circ$.
   - Рухомий промінь $OB$, який учень може обертати за допомогою миші/тачу або кнопок `- 5°` / `+ 5°`.
   - Градусна дуга між променями $OA$ та $OB$ із живим підписом кута.
2. **Панель зворотності та знань**:
   - Індикатор типу кута (Гострий $<90^\circ$, Прямий $=90^\circ$, Тупий $>90^\circ$).
   - Кнопка «Зафіксувати вимірювання».
