# Звіт про аналіз жорстко закодованих навчальних матеріалів

## 1. Виявлені жорстко закодовані сценарії та діалоги
Нижче наведено список файлів та рядків, де було виявлено наративний контент безпосередньо у вихідному коді (src/), а не у папці /content:

### src/services/contentLoaderService.ts
- **Вилучено**: Раніше тут містилися сценарії 3-х уроків та дефініції персонажів. Тепер метод `getStoredCustomVolumes` працює лише з LocalStorage та зовнішніми файлами.

### src/components/story/KhortytsiaDefenseEpisodeModal.tsx
- **Весь файл**: Містить жорстко прописані історичні довідки про 1556-1557 роки, князя Дмитра Вишневецького та хана Девлет-Ґерая. Також містить конфігурацію балістичної гри з текстами успіху/помилок.

### src/components/layout/YamlImportResolverModal.tsx
- **Рядок 232-260**: Приклад YAML сценарію (Бобер Брус).
- **Рядок 286-316**: Приклад математичного YAML (Отаман Дмитро).
- **Рядок 350-373**: Приклад історичного YAML (Запорозький Городок).
*Примітка: Це приклади для користувача, але вони дублюють наратив.*

### src/features/importer/DropZoneModal.tsx
- **Рядок 350-365**: Сценарій уроку у специфікації системного промту для ШІ.

### src/components/story/IslandScene.tsx
- **Рядок 73**: Текст "Острів Хортиця — База Експедиції".

## 2. Виявлені захардкоджені значення вправ
- **src/components/learning/CatchFormulaMiniGame.tsx**: Були виявлені жорсткі значення `20 + 10 = 30`, `30 + 7 = 37`. (Вже замінено на універсальні алгоритми).
- **src/services/contentLoaderService.ts**: У методі `formatQuestToChapter` були захардкоджені значення `24`, `13`, `37`, `77`. (Вже замінено на динамічне зчитування з блоків).

## 3. Аналіз структури /content
Папка `/content` тепер містить лише структуру директорій (файли видалено згідно з запитом):
- `content/grades/grade-05/subjects/math/chapters/`
- `content/grades/grade-05/subjects/math/assets/avatars/`

## 4. Висновок та рекомендації
- Усі навчальні сценарії з `src/services/contentLoaderService.ts` видалено з коду.
- Модальне вікно `KhortytsiaDefenseEpisodeModal.tsx` рекомендовано переробити на динамічне, яке зчитує дані з YAML файлів у `/content`, або видалити як застарілий демо-компонент.
- Система тепер безпечно запускається при порожній папці `/content` завдяки динамічним імпортам та перевіркам на `undefined`.
- Помилка ініціалізації CrashGuard при відсутності контенту виправлена.
