## 🌟 Основна ідея та місія проєкту

**«Відродження Нації — Навчальний простір»** — це інноваційна, інтерактивна освітня платформа нового покоління, створена для забезпечення якісної, глибокої та захопливої освіти учнів **1–12 класів**. 

Головна мета проєкту полягає у трансформації класичного шкільного навчання з пасивного запам'ятовування на активну дослідницьку пригоду. Платформа об'єднує фундаментальні шкільні предмети (точні науки, природничі дисципліни, гуманітарний цикл, трудове навчання та практичне креслення) із сучасними інтерактивними симуляторами, елементами гейміфікації, життєвими картриджами практичних навичок та захищеною авторською студією для педагогів.

Проєкт створено з урахуванням сучасних педагогічних методик, європейських стандартів цифрової доступності (WCAG) та принципів глибокого занурення в освітній контекст без відволікаючих факторів чи зайвої реклами.

## 🏛️ Ключові архітектурні модулі та можливості

1. **Повна навчальна програма (1–12 класи):**
   - Структурований каталог предметів і курсів, охоплюючи математику, фізику, хімію, біологію, історію, мови, інформатику та технології.
   - Інтерактивні предметні віджети та симулятори (оптичні лабораторії, баланс-фізика, логічні вентилі, матричні калькулятори, фонемні транскриптори, тригонометричні транспортири та інструменти практичного читання й побудови креслень).

2. **Життєві картриджі (Life Cartridges):**
   - Практичні модулі з фінансової грамотності, правової свідомості, екології, медіаграмотності, психологічної стійкості (Resilience Arena) та соматичних паузах для збереження ментального здоров'я учнів.

3. **Студія автора 2.0 та Командний Co-op режим:**
   - Захищений простір для вчителів і методистів для створення власних курсів, редагування кроків, налаштування завдань та керування навчальним контентом.
   - Інтерактивний командний режим для спільного проходження викликів та розв'язання практичних кейсів.

4. **Економіка знань та система мотивації:**
   - Гейміфікована система досягнень, радар розвинутих якостей учня, внутрішній баланс ресурсів (енергія, знання, досягнення) та система зворотного зв'язку.

5. **Офлайн-персистентність і надійність:**
   - Надійне локальне зберігання прогресу завдяки Dexie (IndexedDB) та механізму CrashGuard, що гарантує збереження досягнень навіть при нестабільному інтернет-зв'язку.

## 🛠️ Технологічний стек

- **Фронтенд:** React 19, TypeScript, Vite.
- **Стилізація:** Tailwind CSS v4, адаптивні CSS-змінні, підтримка 8 глобальних палітр (включно з монохромними режимами).
- **Стейт-менеджмент:** Zustand для реактивного керування станом сесій, профілю та налаштувань.
- **Зберігання даних:** Dexie.js (IndexedDB) + LocalStorage.
- **Інструментарій візуалізації:** SVG-графіка з хетчингом, кастомні інтерактивні Canvas-рушії.
- **Автоматизація та CI/CD:** GitHub Actions (автоматична перевірка лінтінгу TypeScript, аудит меж інтерфейсу, синхронізація з публічним репозиторієм організації та деплой на GitHub Pages).

## 🚀 Початок роботи та розробка

Для запуску проєкту локально виконайте такі кроки:

```bash
# Встановлення залежностей
npm install

# Запуск локального сервером розробки (порт 3000)
npm run dev

# Перевірка типів TypeScript
npm run lint

# Аудит меж інтерфейсу
npm run audit:ui

# Збірка виробничого бандлу
npm run build
```
